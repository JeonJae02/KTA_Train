# 조치 없는 컨베이어 경고 검토 — 현장이 놓쳤나, 모델이 민감했나

> 근거 노트북: [`경고_검토.ipynb`](경고_검토.ipynb) · 대상: 컨베이어 경고 127건 중 사건 검토(C01~C05)에서 라벨이 없던 110건 + C03에서 보류한 md_fwd 주입 시간 3건 (10-26 ~ 11-11) · 작성 2026-11-13

## 한 줄 결론

**진짜인데 현장이 안 본 것은 대차 두 칸(경고 10건)이고, 나머지 대부분(101건)은 모델이 민감했다.** 민감했던 이유는 세 가지로 모인다.
- 켜짐 길이 경고가 엣지 실시간 칸에서만 잠깐 문턱을 넘는다.
- 구동부 판정이 재가동 직후 표본이 적을 때 시작된다.
- 유닛 기준은 DB로 잡혔는데 엣지는 시간 지표를 일정하게 길게 잰다.

## 1. 기준 — C03(TP)에서 확신을 준 것

| C03 W0069가 TP였던 근거 | 여기서 본 것 |
|---|---|
| 지속 — 같은 센서·대차에서 며칠씩 같은 모양 | 엣지 가동일 기록(하루 칸)에서 그 칸이 이상이었던 날 수 |
| 재현 — DB로 다시 돌려도 같은 값 | 같은 시간 DB 재생 판정에 그 칸이 뜨나 |
| 크기 — 문턱을 넉넉히 넘음 | 하루 칸 값, 경고 순간의 DB z |
| 물리적 설명 | 재가동·측정 차이 같은 다른 설명이 없나 |

가르는 순서는 설계 문서 5-2와 같다.
1. 데이터 문제인가 → `재가동과도` 등
2. 피처가 날마다의 흔들림 넘게 실제로 벗어났나 → 아니면 `모델과민`
3. 뚜렷하게 오래 벗어났나 → `현장놓침의심` → `FIELD_CHECK`

증거 자료는 다음과 같다.
- 엣지 가동일 기록(09-10 ~ 11-05, 10-26부터 엣지 실시간)
- DB 재생 두 개(10-26 ~ 11-05, 11-05 ~ 11-11). 11-05 이후는 엣지 기록이 없어 재생의 하루 칸으로 대신했다.

## 4. 모델이 민감했던 것

### 4-1. 대차 칸 63건 — 엣지 실시간 칸에서만 잠깐 넘음 (C-04)

- 대부분 "표식 뒤쪽 이물"(켜짐 길이 변화)이다. 4건은 앞쪽 이물이 섞였다.
- 경고가 난 날 **엣지 자신의 하루 칸**에서 그 대차의 켜짐 길이 편차는 최대 +1.2(문턱 +3)이고 재감지는 0이다.
- DB 재생에서도 한 번도 재현되지 않는다. 대부분 몇 시간짜리다.
- C02의 W0098과 같은 종류다. 실시간 칸(최근 20번 통과)의 켜짐 길이가 잠깐 문턱을 넘은 것으로 보인다. C02에서 엣지의 켜짐 길이가 DB보다 한 칸 긴 경우가 27%였다.

### 4-2. 구동부 22건 — 재가동 직후 (C-06)

- 경고가 켜진 32번이 **모두 재가동(또는 엣지 모델 시작) 뒤 25분 안**이다.
- 대부분 속도 창 표본이 90~440개뿐일 때다. 11번은 DB 재생도 같은 몇 분 안에 문턱을 넘는다.
- 정속 속도 비율은 매일 0.2743~0.2745(기준 0.2744)라 구동부는 멀쩡하다.

### 4-3. 유닛 14건 — 엣지·DB 측정 차이와 2,000사이클 전환 (C-07)

**엣지가 잰 유닛 시간 지표가 DB보다 일정하게 길다.** 같은 날끼리 비교했다.

| 지표 | DB | 엣지 기록 |
|---|---|---|
| md_fwd 주입 시간 | 0.62 ~ 0.65초 (10-19 전후 계단 없음) | 0.66 ~ 0.69초 |
| md_rev 스톱퍼 후진 | | +0.006 ~ 0.011초 |
| 에어백 노즐 후진 | | +0.005 ~ 0.012초 |
| 에어백 스톱퍼 후진 | 같음 | 같음 |

- 판정 기준(`UNIT_REF`·씨앗)은 DB로 잡혔고, 10-26부터 엣지 값으로 판정한다. 그래서 DB에는 없는 "느려짐"이 생긴다.
- md_fwd 주입 시간 기준값은 0.899초로 실제(DB 0.62)와도 동떨어져 있다. "빨라짐 3일 승인"으로 기준이 0.62대로 옮겨 간 뒤 엣지의 0.68을 느려짐으로 봤다.

**대부분 오늘 사이클이 막 2,000개를 넘긴 순간(2,001 ~ 2,224개)에 켜졌다.**
- 판정 근거가 "어제 기록"에서 "오늘 지금까지의 평균"으로 바뀌는 순간이다. 아침 시작 구간이 많이 섞여 평균이 높다.
- 그 순간 DB z는 2.7 ~ 4.7로 문턱(5) 아래다. 엣지 측정 차이만큼 더해져 넘었다.

나머지 두 건은 이렇다.
- W0282(md_rev 걸림 거리): σ 하한 0.05카운트가 평소 날 흔들림(±0.1)보다 작다.
- W0283(에어백 노즐 후진, 57시간): 11-07·08이 짧은 날이라 11-06 기록이 주말 내내 판정 근거로 남았다.
