## 한 줄 결론

10-19 새벽 순환 운전에서 **P2는 가동 지령이 들어가 있었다. 트립도 없고 흡입 압력도 정상이었다. 그런데 유량이 평소의 5%밖에 안 나왔다.** 모터는 도는데 펌프가 토출하지 못한 갑작스러운 고장이다. 10-18 08:38까지는 정상이었고, 그 전 자동 운전에도 전조가 없었다.

**우리 모델은 이 고장을 보지 못했다(FN).**
- 모델은 자동 운전 사이클만 판정한다. 고장 상태로 자동 운전을 한 적이 없어서 판정할 사이클이 없었다.
- 화면에는 P2가 "정지"로 표시됐을 것이다.

그때 떠 있던 P2 경고("헤드·배관 저항 증가")는 **다른, 실제로 있는 현상**이다. P2 라인 저항이 10-06과 10-13 두 번에 걸쳐 19% 올랐고, 펌프 교체 뒤에도 그대로다. 이 경고에 맞는 조치는 아직 없다(현장 확인 요청).

- 펌프 교체로 저항은 바뀌지 않았다.

## 3. 그때 모델은 무엇을 냈나, 왜

| 시점 | 모델 화면 | 이유 |
|---|---|---|
| 10-05 ~ 10-17 | P2 거의 내내 "알림" 상태 (10-13부터 창 98%). 10-15 로그 시작부터는 P2·I2 묶음 "**헤드 토출 저항 증가 · POL·ISO 동시 압력 상승 (노즐·믹싱헤드 점검)**" | `r_phys`·`P0` 편차가 정상 한계(±1)를 넘음(10-13~17 일별 중앙값 z 1.26~1.41·1.13~1.38). I2도 같은 방향(10-15~17 `r_phys` z 0.9)이라 헤드로 묶임 |
| **10-19 05:28~05:52 (고장 중)** | P2 상태 **"정지"**. 경고는 10-17 20:15의 "헤드 토출 저항 증가"가 마지막 상태로 남아 있었을 것 | 유량 58~75 < `CIRC_MIN_FT`(300)이라 "대기 순환"이 아니라 "정지"로 분류된다(`pump_realtime._tick_state`). 증압 비트가 꺼져 있어 사이클도 없고 판정도 없다. 모델은 가동 지령(`P00460`, `Pump_Run_P2`)을 읽지 않는다 |
| 10-19 06:51 (교체 후 첫 자동 사이클) | P2·I2 창이 비워져 일단 "정상" | 30분 넘게 멈췄다가 재가동하면 창을 비운다(설계대로) |
| 10-19 06:57 ~ 10-23 | P2 다시 "알림". I2가 빠져서 P2 단독 "**토출 배관 저항 증가**"로 바뀜. 10-23 오후부터 다시 I2와 묶여 "헤드" | P2 `r_phys` z 0.84, `P0` z 1.12로 여전히 높다(저항 그대로). 새 펌프의 토출 감소(`pump_resid` z −0.8)는 정상 한계(±1) 안이라 사유가 되지 않았다 |

`r_phys`가 교체 뒤 1.13 → 1.08로 내려간 건 **저항이 줄어서가 아니다.** 기대 압력을 실제 유량이 아니라 "회전수 × r"로 계산하기 때문에, 새 펌프가 덜 토출하면 압력이 내려가 `r_phys`도 따라 내려간다. 순환 K가 그대로인 것으로 확인된다. 펌프 마모를 "유량·압력 동시 감소"로 잡도록 설계했기 때문에 생기는 동작이다.

## 4. 모델의 의미 vs 현장의 의미

| | 모델 | 현장 |
|---|---|---|
| 대상 | P2 (+ I2, HD1-2) | P2 |
| 무엇 | 같은 유량 대비 압력이 높다 → 저항 증가 | 압력이 안 걸린다 → 펌프 고장 |
| 방향 | 압력 ↑ | 압력 ↓ (거의 0) |
| 권고 / 조치 | 노즐·믹싱헤드 점검 | 펌프 교체 |
| 조치 뒤 | 저항 경고 그대로 (저항 그대로이므로 맞음) | 토출 회복 |

**같은 펌프, 다른 두 현상이다.**
- 모델은 진행 중인 저항 증가를 2주 동안 계속 말했다. 일지에는 그에 맞는 조치가 없다.
- 현장이 조치한 것은 순환 시작 때 갑자기 드러난 펌프 고장이다. 모델은 이 고장을 판정할 상태(자동 운전)에 들어가지 못했다.

둘 사이의 인과는 확인되지 않았다. 다만 토출 압력이 19% 높으면 펌프 축 토크도 그만큼 커진다. 그래서 축 파손이었다면 기여했을 가능성은 있다. 이건 가설이고, 현장에서 고장 부위를 확인해야 한다.

## 7. 현장 확인 요청

1. **교체한 P2 펌프의 고장 부위**는 무엇이었나? 축, 커플링, 기어, 키 등. 축 파손이라면 저항 증가(토출 압력 ↑)와의 관련을 볼 수 있다.
2. **HD1-2 POL 라인 저항**: 10-05→06과 10-12→13 밤사이에 HD1-2 POL 쪽(필터, 토출 배관, 헤드 입구, 노즐)에 손댄 작업이나 원료 변경이 있었나? 지금도 교체 전과 같은 수준(+19%)이다. 순환할 때 원료가 헤드를 거쳐 돌아가는지, 펌프 근처에서 바로 돌아가는지도 알려 주면 구간을 좁힐 수 있다.
3. **펌프 교체 뒤 HD1 Auto-Cal을 했나?** 데이터상 10-24까지 P2가 설정보다 약 1.3% 덜 나가고 있다(POL:ISO 비율이 그만큼 어긋남).
4. 교체된 새 펌프의 용량(cc/rev)이 이전 펌프와 같은가? 1 Hz당 유량이 1.5% 낮다.
