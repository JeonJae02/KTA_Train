## 2. 무엇을 TP · FP · FN으로 셌나

| 판정 | 정의 | 단위 |
|---|---|---|
| **TP (조치 확인)** | 일지에 조치가 있고, 조치 전 7일 안에 같은 설비 경고가 떠 있었고, 모델 피처가 조치 뒤 정상으로 돌아왔다 | 사건 (재현율) · 경고 (정밀도) |
| **TP (패턴 가정)** | 조치는 없지만 확인된 TP 두 건과 같은 모양이다. 진입 센서가 표식 앞에서 무언가를 다시 감지하고, 그 칸이 하루 칸에서 2일 넘게 이상이거나 DB 재생으로 재현된다 | 경고 |
| **FP** | 조치도 없고 TP 모양도 아닌 경고 | 경고 |
| **FN** | 모델이 볼 수 있는 고장인데 조치 전 7일 안에 경고가 없었다 | 사건 |
| OUT (분모 제외) | 모델이 받지 않는 신호의 고장. 캐리어 에어 누수(에어백 감지 신호 없음), 행거(2라인 PLC 밖), 예비 캐리어 | 사건 |
| TN | 세지 않음 | — |

정의 원문: [`CM_검토_설계.md`](../CM_검토_설계.md) 2절 · 5절

## 3. 혼동행렬 (82% 기준)

### 3-0. 전체 혼동행렬 — 네 칸

수정 C-04 · C-06 · C-07을 적용하고, 강 + 약 패턴을 TP로 친 경우다.

**(가) 보고서 값 기준 — 칸마다 원래 정의된 단위**

| | **경고 있음** | **경고 없음** |
|---|---|---|
| **실제 이상 있음** | **TP 27** (경고) — 조치 확인 2 + 패턴 가정 25 | **FN 0** (사건) — 범위 안 사건 C03 · C06 모두 조치 전에 경고가 있었다 |
| **실제 이상 없음** | **FP 6** (경고) — md_rev 스톱퍼 3, P00141 대차 18 2, P00459 대차 28 1 | **TN 114** (감시 대상 × 생산일) — 아래 (나)와 같다 |

- 정밀도 = 27 / (27 + 6) = **81.8%**
- 재현율 = 2 / (2 + 0) = **100%**
- F1 = **0.90**

**(나) 네 칸을 같은 단위로 — 감시 대상 10개 × 생산일 18일 = 180칸**

- 감시 대상 10개: 진입 센서 6개(P00140 · P00141 · P00154 · P00164 · P00451 · P00459), 유닛 3곳(md_fwd · md_rev · airbag), 구동부
- 생산일 18일: 10-26 ~ 11-16 중 자동운전 3시간 이상인 날

| | **경고 있음** | **경고 없음** | 합 |
|---|---|---|---|
| **실제 이상 있음** | **TP 50** | **FN 0** | 50 |
| **실제 이상 없음** | **FP 16** | **TN 114** | 130 |
| 합 | 66 | 114 | **180** |

| 지표 | 수정 적용 가정 | 지금 모델 (같은 방식) |
|---|---|---|
| 정밀도 TP / (TP + FP) | **75.8%** (50 / 66) | 31.6% (50 / 158) |
| 재현율 TP / (TP + FN) | **100%** (50 / 50) | 100% |
| 특이도 TN / (TN + FP) | **87.7%** (114 / 130) | 16.9% (22 / 130) |
| 정확도 (TP + TN) / 전체 | **91.1%** (164 / 180) | 40.0% (72 / 180) |
| F1 | **0.86** | 0.48 |

- 지금 모델의 칸 수는 TP 50 · FP 108 · FN 0 · TN 22다.
- **한 칸의 판정:** 그날 그 대상에 경고가 하루 중 한 번이라도 떠 있으면 "경고 있음"이다. 그 경고가 TP(조치 확인 또는 패턴)이거나, 그날 그 대상에 범위 안 조치(C03 10-31 · C06 11-12, 둘 다 P00451)가 있으면 "실제 이상 있음"이다.
- (가)와 정밀도가 다른 이유는 단위다. 경고 기준은 경고 하나가 한 번 세어진다. 칸 기준은 오래 떠 있는 경고가 날마다 세어진다. 그래서 몇 주씩 이어진 md_rev 스톱퍼 경고(W0082, 242시간)가 FP 칸 16개 중 13개를 차지한다.
- md_rev 스톱퍼도 C-07에서 빠진다고 보면(7절 2) FP 3 · TN 127이 되고, 정밀도 94.3% · 정확도 98.3%다.
- FN 0은 "범위 안 조치 사건이 있던 날에는 모두 경고가 있었다"는 뜻이다. 일지에도 없고 경고도 없던 실제 이상은 셀 수 없다.

## 5. 같은 혼동행렬의 다른 기준 — 숫자를 쓸 때 같이 적을 것

| 기준 | 경고 정밀도 | 비고 |
|---|---|---|
| 지금 모델, 조치로 확인된 것만 TP | 2 / 131 = 1.5% (확인 대기 31건 제외) · 2 / 162 = 1.2% | 현장은 우리 경고를 보지 않았다. 그래서 "조치 없음 = 틀림"은 아니다 |
| 지금 모델, 강 + 약 패턴 = TP | 27 / 162 = 16.7% | |
| **수정 적용 가정, 강 + 약 패턴 = TP (보고서 값)** | **27 / 33 = 81.8%** | |
| 수정 적용 가정, 강한 패턴만 TP | 19 / 33 = 57.6% | 이때 F1 = 0.73 |
| 수정 적용 가정, 확인 대기를 모두 FP | 2 / 33 = 6.1% | 아래 한계 |
| 케이스 기준 (같은 증상의 반복을 하나로) | 6 / 11 = 54.5% | 지금 모델은 6 / 80 = 7.5% |

## 7. 한계

1. **고친 모델로 다시 돌린 값이 아니다.** 수정을 v2_2_1에 반영한 뒤 같은 기간을 다시 돌려야 확정된다. 수정 때문에 새로 생기는 경고는 세지 못했다.
2. **패턴 TP 25건은 현장 확인 전이다.** 이 중 13건은 현장 확인을 요청했다(P00459 대차 9, P00164 대차 20). 확인 결과에 따라 정밀도가 6 ~ 82% 사이에서 정해진다.
3. **표본이 작다.** TP 사건 2건, 측정 기간 3주다.
4. C03 경고(W0069)는 9월부터 매일 켜져 있던 상시 경고였다. 사전 경고 시간 124.9 h는 엣지 경고 로그가 시작된 10-26부터 잰 값이다. PLC 첫 증상(10-30 20:07)부터 재면 109.0 h다.
