# 기계실·공무반 업무 이력

폴더의 PDF 4개(47쪽), XLS 1개, PNG 1개를 확인해 **라인별 이슈·조치 검색용 CSV**로 정리했습니다. 실제 작업일이 적힌 업무는 2026-08-31부터 포함되며, 일지 작성일은 2026-10-19까지입니다.

## 먼저 열 파일

**[01_이슈조치.csv](01_이슈조치.csv)**를 먼저 여세요. 정기점검·이상무·일반 지원업무를 제외한 **175개 작업기록, 라인별 181행**입니다. 이것은 실제 고장 175건이라는 뜻은 아닙니다. 예방 교체·시험·설치·조건 조정도 포함하며, 부서 간 같은 사건으로 보이는 기록도 근거가 다르면 별도 보존했습니다.

- [02_전체업무.csv](02_전체업무.csv): 정기점검·청소·정비·이상무·지원업무까지 274개 작업기록, 라인별 446행.
- [03_확인사항.csv](03_확인사항.csv): 작업일·라인 미기재, 중복 의심, 시간·측정값 차이 등 37항목.
- [04_근무시간.csv](04_근무시간.csv): 이미지에 있는 주간·야간 시간표 16구간. 작업 이력과 구분했습니다.
- [05_파일목록.csv](05_파일목록.csv): 처리한 원본 6개, 쪽수·행수, 원본 경로 및 SHA-256.

모든 CSV는 **UTF-8 BOM / 쉼표 구분 / 첫 줄 열 이름**입니다. 엑셀에서 한글을 읽을 수 있도록 저장했습니다. CSV 자체는 색상·열 너비·필터 설정을 저장하지 않습니다.

## 필터 사용 예

엑셀에서 파일을 열고 첫 행을 선택한 뒤 **데이터 → 필터**를 켜세요. 필요하면 열 너비를 자동 맞춤하세요.

1. **1라인의 펌프 관련 조치**: `라인번호 = 1`, `펌프관련 = 예`.
2. **발포2라인의 펌프만**: `라인번호 = 2`, `공정표기 = 발포`, `펌프관련 = 예`.
3. **호스 교체**: `부품태그`의 텍스트 필터에서 `호스 포함`, `조치`에서 `교체 포함`.
4. **에어백·리미트 스위치**: `부품태그`에서 `에어백 포함` 또는 `센서·스위치 포함`.
5. **특정 캐리어**: `설비상세`에서 `캐리어(41번) 포함` 등으로 검색. 기계실 자료는 `41번 캐리어`처럼 어순이 다를 수 있으므로 번호와 부품명을 함께 확인하세요.
6. **비가동 기록**: `생산영향`에서 `비가동` 또는 `라인 정지` 포함. `비가동 없음`은 제외하세요. 공무반 자료처럼 생산영향이 적혀 있지 않은 기록은 `미기재`입니다.
7. **결과 확인이 필요한 기록**: `결과 = 결과 미기재`. 조치가 적혔다고 정상 복구까지 확정하지 않았습니다.

`펌프관련 = 예`는 펌프 자체 교체뿐 아니라 펌프 모터·커플링·유량계·진공필터 등의 연관 조치도 포함합니다. 실제 교체 대상을 확인하려면 **조치** 열을 함께 보세요. `부품태그`는 한 작업의 여러 관련 부품을 세미콜론으로 연결했으므로 **같음**보다 **포함** 필터가 적합합니다.

## 열과 날짜의 의미

- **작업일**: 원문의 비고·작업일자 또는 명확한 반복기호로 확인한 실제 날짜입니다. 작성일로 임의 대체하지 않았습니다. 빈칸은 작업일 미기재입니다.
- **기준일**: 정렬 편의를 위한 날짜입니다. 작업일이 있으면 작업일, 없으면 일지 작성일입니다. **작업일 미기재 행의 기준일을 실제 작업일로 사용하면 안 됩니다.**
- **날짜근거 / 일지작성일 / 확인메모**: 날짜를 어떻게 읽었는지, 어떤 점이 불확실한지 적었습니다.
- **라인번호**: `1`, `2`, `3`, `미기재`. 공통 업무는 1·2·3라인에 각각 한 행씩 펼쳤습니다.
- **공정표기**: 원문 기준 `발포`, `COLD`, `발포/COLD 표기 혼재`. 두 부서의 표기가 같은 물리적 설비를 뜻하는지는 임의 확정하지 않았습니다.
- **설비분류 / 부품태그**: 검색 편의를 위한 분류입니다. 원문에 없는 고장 원인·부품 사양은 추가하지 않았습니다.
- **기록시간 / 기록구간_분**: 원문 시간 구간과 그 구간의 시각 차이입니다. **작업시간·관찰시간일 수 있으므로 비가동 시간으로 합산하면 안 됩니다.** 단독 시각은 소요시간을 계산하지 않았고, 떨어진 두 구간은 각 구간만 합쳤습니다.
- **원문소요_분**: 공무반 표에 직접 적힌 분 값입니다. 기계실 일지에는 해당 숫자가 없어 빈칸입니다.
- **작업ID / 적용범위**: 하나의 원문 작업을 여러 라인에 펼친 경우 같은 ID를 사용합니다. 공통 작업 건수를 셀 때는 **작업ID의 고유 개수**를 세세요. 같은 작업ID의 시간을 라인 수만큼 더하면 과다 집계됩니다.
- **중복의심**: 원문 자체에 같은 내용이 두 번 적힌 C-105/C-106만 `예`로 표시했습니다. 두 행 모두 남겼으므로 실제 별도 작업인지 확인 전에는 단순 합산하지 마세요.
- **출처 / 출처수**: 원본 파일, PDF의 실제 페이지(1부터), 표의 NO를 기록했습니다. 한 행의 출처가 여러 개면 세미콜론으로 병기했습니다.

## 중복과 누락을 처리한 기준

- 10/12·10/13 기계실 일지는 두 PDF에 중복 수록되어, 같은 내용을 한 번만 정리하고 두 파일의 페이지를 병기했습니다.
- 공무반 PDF와 XLS에 겹치는 **10/12의 동일 작업 5행**은 통합했습니다. 1·2·3라인 공통 1행은 라인별로 3행으로 펼쳐지므로 필터용 CSV에서는 총 7행의 출처가 두 개입니다.
- 서로 다른 부서 자료에서 날짜·부품이 유사해도 시간·설명에 차이가 있으면 합치지 않았습니다. 특히 9/7 컴프레서, 9/14 POL 펌프, 10/8 POL 펌프, 10/5 클로징 등의 차이는 확인사항에 적었습니다.
- 원문 NO.105/106의 9/30 COLD2 S/P 온조기 펌프 교체는 완전히 같은 기록이지만 실제 두 작업인지 알 수 없어 각각 보존했습니다.
- 라인이나 날짜가 빈칸인 항목을 위 행에서 무조건 이어받지 않았습니다. `〃` 등 명확한 반복기호만 이어받았습니다.
- 배관·호수→호스, 메터→미터, 크로징→클로징 등은 검색 가능한 표현으로 정리했습니다. `올림프스`, `발로프센서`처럼 사양을 확정하기 어려운 원문 용어는 유지했습니다.
- 공무반 PDF의 원문 145행을 모두 반영했고, 소요시간 합계 **14,320분**이 원문의 합계와 일치하는지 확인했습니다. XLS는 35행과 원문 합계 **2,770분**을 대조했습니다. 이 합계는 원문 행 확인용이며, 중복 제거·공통라인 펼침 후 CSV의 합계를 뜻하지 않습니다.
